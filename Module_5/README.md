# Module_5

Задания 1–4 модуля 5 доступны из одного меню.

## Запуск Android

Распакуйте ZIP. В Android Studio выберите File → Open и откройте папку `Module_5` с `settings.gradle.kts`. Для Gradle JDK используйте JBR Android Studio или JDK 17+. Установите Android SDK Platform 36, дождитесь Sync, выберите конфигурацию `app` и устройство с Android 10 (API 29) или новее. Нажмите Run. В меню приложения выберите нужное задание.

Сборка из PowerShell в корне проекта

```powershell
.\gradlew.bat :app:assembleDebug
```

Стек проекта включает Kotlin 2.0.21, Gradle Wrapper 8.13, AGP 8.13.2 и Jetpack Compose. Исходники приложений и тестов написаны на Kotlin. Для запуска JVM-тестов на Windows при сбое ClassNotFoundException из каталога с кириллицей используйте путь с латинскими буквами, например `C:\AndroidTasks\Module_5`.

## Задания

| Номер | Экран |
|---|---|
| 1 | Дневник |
| 2 | Личная галерея |
| 3 | Расширенная галерея |
| 4 | Список задач |

Дневник хранит записи во внутреннем хранилище в отдельных TXT-файлах. Имя новой записи содержит отметку времени и заголовок, если он задан. Список загружается при открытии и обновляется по одной записи при сохранении или удалении.

Галерея использует системную камеру и личную папку Pictures приложения. Расширенная галерея работает с этой же коллекцией и сохраняет копию через MediaStore. Экспорт доступен из меню плитки и из просмотра снимка. Для AVD включите виртуальную камеру.

База TodoList восстановлена по тексту и скриншотам задания 4. Файл `app/src/main/assets/todo_seed.json` содержит учебные начальные задачи. Заголовок, описание и отметка выполненности соответствуют примеру. Room сохраняет задачи и отметку импорта в одной транзакции. При следующем запуске выполненный импорт пропускается, в том числе после удаления всего списка. Переключатель «Цвет завершенных» хранится в DataStore. У дневника и списка задач отдельные хранилища.

```powershell
.\gradlew.bat :app:connectedDebugAndroidTest
```

Инструментальный тест использует отдельную SQLite-базу и проверяет повреждённый JSON, импорт после исправления, параллельные попытки импорта, изменение задач и открытие пустой базы после удаления.
